# Material 素材管理模块规范

## 模块概述

Material 素材管理模块提供图文素材、新闻资讯、短语、投票和页面访问统计等功能的完整管理。

- **子模块**: api, core, mapper, service, starter
- **包名**: cn.jia.mat
- **版本**: 1.1.3-SNAPSHOT

## 核心功能

### 1. 媒体素材管理

| 功能 | 说明 |
|------|------|
| 素材创建 | 创建新媒体素材（文件上传/内容写入） |
| 素材列表 | 分页查询媒体素材列表 |
| 素材详情 | 获取素材完整信息（含链接） |
| 素材内容 | 读取素材文件内容 |
| 素材更新 | 更新素材信息 |
| 素材删除 | 删除素材及对应文件 |
| 素材上传 | 上传文件或内容创建素材 |
| 缩略图 | 生成/获取素材缩略图 |

### 2. 新闻资讯管理

| 功能 | 说明 |
|------|------|
| 新闻创建 | 创建新闻资讯 |
| 新闻列表 | 分页查询新闻列表 |
| 新闻详情 | 获取单条新闻详情 |
| 新闻更新 | 更新新闻内容 |
| 新闻删除 | 删除新闻 |

### 3. 短语管理

| 功能 | 说明 |
|------|------|
| 短语创建 | 创建短语 |
| 短语列表 | 分页查询短语列表 |
| 短语详情 | 获取短语详情 |
| 短语更新 | 更新短语 |
| 短语删除 | 删除短语 |
| 短语点赞 | 对短语进行点赞/踩操作 |

### 4. 投票管理

| 功能 | 说明 |
|------|------|
| 投票创建 | 创建投票（含问题和选项） |
| 投票列表 | 分页查询投票列表 |
| 投票详情 | 获取投票完整信息（含问题和选项） |
| 投票更新 | 更新投票信息 |
| 投票删除 | 删除投票 |
| 投票提交 | 提交投票选项 |
| 投票统计 | 获取投票结果统计 |

### 5. 提示信息管理

| 功能 | 说明 |
|------|------|
| 提示创建 | 创建提示信息 |
| 提示列表 | 分页查询提示列表 |
| 提示详情 | 获取提示详情 |
| 提示更新 | 更新提示 |
| 提示删除 | 删除提示 |

### 6. 页面访问统计

| 功能 | 说明 |
|------|------|
| PV记录 | 记录页面访问日志 |
| PV统计 | 查询页面访问统计数据 |
| 访问列表 | 分页查询访问记录 |

## 核心实体

| 实体 | 说明 |
|------|------|
| MatMediaEntity | 媒体素材（标题、类型、URL、内容等） |
| MatNewsEntity | 新闻资讯（标题、摘要、内容、作者等） |
| MatPhraseEntity | 短语（内容、标签、点赞数等） |
| MatVoteEntity | 投票主题（标题、描述、截止时间等） |
| MatVoteQuestionEntity | 投票问题 |
| MatVoteItemEntity | 投票选项 |
| MatVoteTickEntity | 投票记录 |
| MatPhraseVoteEntity | 短语点赞记录 |
| MatTipEntity | 提示信息 |
| MatPvLogEntity | 页面访问日志 |

## 依赖模块

- **jia-common-core**: 基础实体和通用工具
- **jia-common-service**: 通用服务实现
- **jia-base-service**: 字典服务（获取模块URL配置）
